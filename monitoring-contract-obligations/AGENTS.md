# Рабочие правила проекта

- PostgreSQL запускается только через `compose.yaml`.
- Пароли из локального Compose не используются в тестовой или продуктивной среде.
- Изменения схемы БД выполняются миграциями, а не ручными правками контейнера.
- Перед добавлением приложения сначала проверяется запуск и доступность PostgreSQL.
